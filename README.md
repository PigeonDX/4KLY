## Build from Source

> The DMG above is easier and already notarized. Build from source only if you need to modify the code.

**Requirements:** Xcode 15.4+, macOS 14+

```bash
git clone https://github.com/tpjuic/4KLY.git
cd 4KLY
open 4Kly.xcodeproj
```

Hit ⌘R in Xcode to build and run.
